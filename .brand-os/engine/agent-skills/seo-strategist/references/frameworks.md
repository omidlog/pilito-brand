# Method and limits

- Archetype first: what the brand actually has (site, app, both) decides the strategy, not a generic checklist.
- Alternatives on a declared qualitative rubric: evidence strength, feasibility, time to signal, brand fit, risk. There are no numeric scores and no ROI.
- Decisions rest on either owner answers (`brand_reasoned`) or quoted platform statements (`cited`). Anything else is `provisional`.
- Official documentation says what a platform states. It is not evidence that a tactic works for this brand. There is no performance data, so outcomes are `not_measured`.
- Limits: deterministic decision catalog (`strategist.ts`). No keyword research tool, no competitor crawling, no Search Console connector.
