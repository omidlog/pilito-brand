# ADR 0002 — Design tokens

## Status

Accepted for 0.1.0.

## Choice

DTCG-style JSON in `brand/tokens`. Color values are sRGB objects with a 6-digit `hex`. Components are optional. When present, the compiler checks they match the hex within 1/255. A small compiler writes CSS custom properties and a TypeScript module. It is not Style Dictionary.

## Why

The template needs a readable source and two exports. A direct compiler is easier to test than a plugin chain, and it keeps EXAMPLE status explicit.

## Deviation

The Design Tokens color module prefers a `components` array as the canonical value. This template treats `hex` as the authored value and derives components when a caller needs them. Groups, aliases of the form `{path}`, dimensions, durations, font families, cubic beziers, numbers, and shadows are supported.

## Figma

`brand/tokens/figma-variables.snapshot.json` is a local stand-in, regenerated by `npm run tokens:build`. It is not a live Figma connection. Drift is “the snapshot variable list matches compiled token paths.” See `docs-internal/FIGMA_SYNC.md`.
